# Vishakha Agrawal's Project Portfolio

Welcome to my main projects repository! This repository contains some of the significant projects I completed as part of my Computer Science and Engineering coursework at the **International Institute of Information Technology, Hyderabad (IIIT-H)**.

## Projects Overview

| Project Title | Description | Key Technologies |
|---------------|-------------|------------------|
| **MERN E-Commerce Platform** | A full-stack e-commerce application allowing users to buy and sell products | React, Redux, Node.js, Express.js, MongoDB, JWT |
| **Distributed Network File System** | A client-server based file system allowing remote file access and modification | C++, Sockets, TCP/IP |
| **Custom Shell** | A custom UNIX shell implementation with support for pipes, I/O redirection | C, Operating Systems Concepts |
| **Dynamic Photo-to-Video Converter** | A web application that converts a series of photos into a video | Python, Flask, HTML/CSS, JavaScript |
| **Veterinary Clinic Database** | A relational database schema and management system for a veterinary clinic | SQL, Database Design |
| **XV6 Scheduling & Networking** | Custom schedulers (LBS, MLFQ) and networked applications (TCP/UDP Tic-Tac-Toe, reliable UDP) in xv6 | C, Operating Systems, Socket Programming |
| **XV6 COW Fork & Concurrency** | Copy-On-Write fork implementation and multi-threaded file manager/sorting system | C, POSIX Threads, Synchronization |
| **Urban Growth Simulation** | Hybrid CA-MLR-GA model predicting Hyderabad's metropolitan expansion (2020-2050) using satellite imagery and machine learning | Python, Google Earth Engine, Cellular Automata, MLR, GA |
| **LST & Land Use Analysis** | Study of Land Surface Temperature changes due to urbanization in Jaipur (2014-2024) | Python, Google Earth Engine, Remote Sensing, Mono-window Algorithm |
